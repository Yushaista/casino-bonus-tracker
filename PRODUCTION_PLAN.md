# Taking this to production: 200 casinos, daily refresh

For a 200-casino production site, I would separate the public frontend from the daily data collection. I would host the static site on **Cloudflare Pages**, with a Python worker running in Docker on a small **DigitalOcean VPS**. This keeps the browsing experience fast and cheap without exposing scraping infrastructure or API credentials to visitors. Each casino would have a defined public source and extraction rules, subject to site permissions and robots.txt. I would schedule polite, rate-limited jobs using a **systemd timer** once per day, with bounded retries for temporary network errors. A blocked source would be recorded as unavailable, never bypassed.

I would use **PostgreSQL** for casinos, offers, source URLs, fetch timestamps and historical changes. Every extracted offer would keep its raw evidence and confidence/validation status, so an AI parsing mistake could be audited. The site would read a cached JSON export, not make live scraping requests on page loads. I would run nightly `pg_dump` backups to separate S3-compatible object storage, retain multiple restore points and test restores regularly. For reliability, I would add Sentry error reporting, structured logs, and a health-check alert if the run fails, produces unusually few records, or has not completed in 26 hours. Bad runs would never overwrite the last known-good data.

I would register the domain with a reputable registrar and use **Cloudflare DNS**, automated HTTPS and SSL certificate renewal at the edge. The VPS would have restricted firewall rules, SSH keys, secrets stored outside the repository and routine patching. For an MVP, I would budget approximately **US$15–35 per month**: VPS $6–12, offsite backups $1–4, domain equivalent $1–2, LLM usage $2–10 and a buffer for monitoring or extra bandwidth; Cloudflare Pages can start free. These are planning estimates, not supplier quotes. I would revisit the architecture once daily scrape times or reliability requirements justify managed Postgres or an independent worker.
